# AI Visit website 1.2.2

本次发布重新打包了智能体插件与 Chrome 扩展，重点是让安装、配对、状态检查和故障排查更清楚。

## 发布文件

- `ai-visit-website-1.2.2.tgz`：Codex/OpenClaw 风格插件包。
- `ai-visit-website-1.2.2.zip`：通用插件目录包。
- `ai-visit-website-chrome-extension-1.5.0.zip`：Chrome 扩展安装包。
- `SHA256SUMS-1.2.2.txt`：发布文件完整性校验值。

## 主要变化

- Chrome 扩展名称统一为 **AI Visit website**。
- 删除人工网页保存、标签/文件夹、导入导出、快捷键、右键菜单和 Reuters 验证界面。
- 保留智能体授权读取所需的生产正文提取器与 Browser Bridge。
- 扩展设置页改为 Pairing token、端口、授权 Origin 和连接状态的智能体专用界面。
- Skill 明确要求 Chrome 读取前先调用 `browser_status`，仅在 `configured=true` 且 `connected=true` 时继续。
- 新增中文安装、使用和故障排查文档。

## 已记录的常见问题

- 扩展选项页不需要一直打开；真正处理任务的是后台 Service Worker。
- 当前 Bridge 按 MCP 调用进程启动，偶发离线时先调用 `browser_status`，等待 5–10 秒后最多重试一次。
- `401` 通常表示扩展保存的 Pairing token 与当前插件不一致。
- `domain_not_authorized` 需要添加目标网站的精确 Origin。
- 经常读取 8 篇不是插件硬编码；数量来自候选发现、智能体选择或部分页面读取失败。
- Reuters sitemap 候选不等于正文证据；遇到 robots、登录、CAPTCHA、拒绝访问或付费墙必须停止。

完整说明见仓库根目录的 `README_CN.md`。
