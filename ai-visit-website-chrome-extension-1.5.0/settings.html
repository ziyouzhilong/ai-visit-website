What this extension does

  • Claims explicit page-read tasks from the local AI Visit website bridge.
  • Uses one visible Chrome tab and returns readable Markdown to the requesting agent.
  • Stops on login, CAPTCHA, access-denied, paywall, or unauthorized redirects.
  • Never returns cookies, passwords, authorization headers, or browser storage.
